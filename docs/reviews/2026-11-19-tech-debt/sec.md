## Verified clean
- RLS on all 34 public tables; private tables have no app grants; anon can execute only invite_preview and report_client_error (both rate-limited, fixed-shape).
- Every SECURITY DEFINER function sets `search_path = ''`; only videos_this_month keeps PUBLIC execute.
- Not-found parity: 14 post RPCs give identical results for a hidden vs a nonexistent post (get_comments, toggle_heart, set_reaction, add_comment, delete_post, edit_post_words, reply_scope, reply_readers, mark_seen, publish_post, set_post_audience, post_viewers, reaction_summary, prepare_media_upload).
- Cross-family child tagging via post_children is blocked by trigger ("child is not linked to this space").
- sign-media: can_view_post before any signing, 404 for not-allowed, 10-min TTL, object keys derived server-side (tg_media_before_insert), wrapped DEKs only via service role, KEK only in env, logs name/code only. notify: bearer-gated, no tokens/emails/URLs logged.
- Crypto: AES-256-GCM chunked STREAM (index + last flag in nonce), CSPRNG only; session in Keychain-wrapped store; offline cache holds ciphertext only.
- Error reports: name/code only, regex-gated client and server.
- No secrets, JWTs, B2/Resend/Supabase keys or private keys in the tree (fixtures fake); no image in any commit carries EXIF/GPS.
