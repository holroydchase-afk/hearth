# Contributing to Hearth

Thanks for taking a look. Hearth is a one-person proof of concept, so the process is light.

- **Found a bug or have an idea?** Open an issue with the template. Say what you expected and what happened.
- **Want to change something?** Open an issue first for anything bigger than a typo, then send a small pull request that does one thing.
- **Test first.** Write a failing test with the ticket ID in its title, then the fix. Run `bash test-all.sh` before you push (see the README for each suite).
- **Privacy rules are not optional.** Never bypass row-level security, never log keys, URLs or captions, and never add real family names, faces or places. Use the personas in `docs/product/PERSONAS.md`.
- **Update `HANDOFF.md`** when your change moves the work.
- **Be kind.** Everyone here follows the [Code of Conduct](CODE_OF_CONDUCT.md).

Security problems go through [SECURITY.md](SECURITY.md), not a public issue.
